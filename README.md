# Telegram Giveaway Web App

Beautiful animated Web App for Telegram giveaways with dark/light theme support.

## Features

- 🎨 Smooth animations
- 🌗 Automatic dark/light theme from Telegram
- 📱 Responsive design
- ✨ Beautiful UI with cards and badges
- 🎯 Multiple status screens (success, already joined, not subscribed, ended)
